# 🚀 SimioDev

Projeto desenvolvido para a Feira de Empreendedorismo e Inovação (**InovaIF**), simulando uma plataforma de venda de cursos de programação básica.

---

## 📖 Sobre o Projeto

O **SimioDev** é uma aplicação web criada com foco educacional e demonstrativo para uma competição de empreendedorismo.  
A proposta do sistema é simular uma plataforma moderna de cursos online voltados para programação básica, apresentando navegação dinâmica, layout responsivo e uma interface intuitiva.

---

## 🎯 Objetivo

Desenvolver um site funcional que represente uma plataforma de venda de cursos de programação, demonstrando conhecimentos em:

- Desenvolvimento Front-end
- Componentização em React
- Navegação entre páginas
- Responsividade
- Organização de projeto

---

## 🛠️ Tecnologias Utilizadas

- React
- React Router DOM
- React Icons
- CSS3
- HTML5
- JavaScript

---

## ⚙️ Funcionalidades

- ✅ Navegação entre páginas utilizando rotas
- ✅ Interface responsiva
- ✅ Componentização reutilizável
- ✅ Estrutura organizada
- ✅ Layout moderno para apresentação em feira tecnológica

## ▶️ Como Executar o Projeto

### 1. Clone o repositório

```bash
git clone <url-do-repositorio>
```

### 2. Acesse a pasta

```bash
cd SimioDev
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```
